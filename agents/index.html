Agents propose.People approve.

The Oasis is where Grateful Giraffes hosts plan and run events. Connect your own AI over MCP and it can draft the event, build the page, keep the guest list and write the emails. Going live, emailing guests, approving a guest and moving a date all wait for your yes.

Step by step

Connect your agent

One address for every agent. Paste it once, sign in to the Oasis, and click Allow. Your agent then acts as you: it can do what you can do on the site, never more.

Claude

  1. Open Customize, then Connectors, then Add custom connector.
  2. Paste the address and sign in to the Oasis.

ChatGPT

  1. Open chatgpt.com/plugins, press the plus button and choose Add custom MCP server.
  2. Paste the address as the MCP server URL and create it. ChatGPT opens the Oasis sign-in.

Cursor

{
  "mcpServers": {
    "the-oasis": { "url": "https://app.grateful.gg/claude/mcp" }
  }
}
  1. Add this to ~/.cursor/mcp.json.
  2. Open Customize in Cursor, turn on the-oasis and sign in to the Oasis.

Gemini CLI

gemini mcp add --transport http the-oasis https://app.grateful.gg/claude/mcp
  1. Run this once in a terminal.
  2. Then type /mcp auth the-oasis in Gemini CLI.

VS Code

  1. Run MCP: Add Server from the Command Palette, choose HTTP and paste the address.
  2. Sign in to the Oasis when VS Code asks, the first time the tools are used.

Claude Code

claude mcp add -s user --transport http the-oasis https://app.grateful.gg/claude/mcp
  1. Run this once in a terminal.
  2. Then type /mcp in Claude Code and choose Authenticate.

Another MCP client that runs on your own computer signs in the same way. An app that signs in from its own website has to be one the Oasis knows: today that is Claude, ChatGPT, Cursor and VS Code.

Agents propose, people approve

What waits for a yes

An agent on the Oasis works the way a good assistant does: it prepares, you decide.

  • A new event is a draftRSVPs stay closed until its host has seen the page and said yes.
  • An email is a preview firstThe agent shows the exact words and how many people get it. It sends only after the host says yes.
  • Approving a guest is a preview firstThe agent shows who it is and what happens, and gets a code. It can go ahead only with that code, after your yes.
  • Moving a date is a preview firstYou see the new date, the note to guests and how many people get it before anything moves.
  • A share card is drawn before it is savedAnd a new opening image goes on the page only once the host picks it.
  • Edits to a page you host are live right awayEach one is noted, and the Grateful Giraffes team gets a summary.
  • Refunds are made by peopleA refund is made by the Grateful Giraffes team, never by an agent.
  • Your agent is you, never moreIt can do what you can do on the site. Every call is logged, up to 60 a minute.
  • Addresses stay privateA street address goes to confirmed guests only. Public pages give the city.

Open data, no sign-in

What any agent can read before anyone connects.

  • app.grateful.gg/events.jsonUpcoming public events as JSON: name, link, start and end, city, and whether RSVPs are open.
  • app.grateful.gg/llms.txtA short guide for language models: what the Oasis is and where everything lives.
  • grateful.gg/agents/tools.jsonThis tool list as JSON.
  • app.grateful.gg/eventsEvery public event page carries schema.org Event data.

Every tool, with an example

What your agent can do once you connect. Each tool shows something you might say and the call your agent makes.

Pages you host

Read a page, then change its words, sections, photos and look.

list_my_events

Reads

The events you host and the landing pages you can edit, with their links.

You say
Which events am I hosting?
Your agent calls
{
  "name": "list_my_events",
  "arguments": {}
}

get_page

Reads

Everything on a page that can change: each section's words, its photos, the sections you added and the run of show.

You say
Read me what's on the Sunday Supper page.
Your agent calls
{
  "name": "get_page",
  "arguments": {
    "event": "sunday-supper"
  }
}

update_page

Changes

Change the words of a page's sections. Only the fields you name change.

You say
Make the headline warmer.
Your agent calls
{
  "name": "update_page",
  "arguments": {
    "event": "sunday-supper",
    "sections": {
      "gathering": {
        "title": "Come hungry, leave full"
      }
    }
  }
}
