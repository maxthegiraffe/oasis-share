How to Connect

Step 1: Get Your Host API Key

First, you'll need a personal host key that lets Claude access only your events:

  1. Sign in to app.grateful.gg
  2. Go to Settings → API & Integrations
  3. Click "Generate Host Key" — save it somewhere safe
Coming Soon

Per-host API authentication is currently being built. Once ready, you'll get a key scoped only to your events.

Step 2: Add Oasis MCP to Claude Desktop

Open Claude Desktop, go to Settings → Developer → Model Context Protocol, and add this connector:

https://mcp.grateful.gg/v1

Then paste your host key when Claude asks for authentication.

Coming Soon

The MCP server endpoint is currently under development. The URL above is illustrative.

Step 3: Start Building

Once connected, just chat with Claude and describe the event page you want. It'll create pages, set up tickets, manage RSVPs, and handle everything else.
